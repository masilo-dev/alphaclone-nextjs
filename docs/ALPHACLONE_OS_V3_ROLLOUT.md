# AlphaClone OS v3 Rollout Map

This rollout is global and brand-preserving. It is separate from Projects V2 backend work.

## Phase 1 — global foundation
- Root-level OS v3 stylesheet loaded for all routes.
- Semantic material levels: canvas, content, elevated, floating, intelligence.
- Selective glass for command/navigation/sheet/popover surfaces.
- Shared spring contracts for Motion/Framer Motion usage.
- Reduced-motion and keyboard-focus guarantees.
- Existing AlphaClone brand colours remain canonical.

## Phase 2 — shell and navigation
- Sidebar and mobile navigation.
- Top navigation and module subnavigation.
- Command palette and contextual floating controls.
- Bonnie drawer and global AI surfaces.

## Phase 3 — Projects reference implementation
- Overview.
- Tasks.
- Timeline.
- Files / Design.
- Activity.
- Financials.
- Calm health/blocker/approval/payment states.

## Phase 4 — business modules
- CRM / clients.
- Leads / prospecting / pipeline.
- Marketing Hub / campaigns.
- Social publishing.
- Documents / contracts / signatures.
- Invoices / Money Hub.
- Calendar.
- Nexus / integrations.
- Settings / admin / controls.

## Phase 5 — public and lifecycle surfaces
- Authentication.
- Onboarding.
- Public landing and marketing site.
- Pricing and product pages.

## Acceptance gates
- No brand palette replacement.
- No Apple trademarks or macOS imitation.
- No glass applied indiscriminately to data-heavy content.
- Keyboard navigation preserved.
- Visible focus states preserved.
- Reduced-motion behavior validated.
- Responsive behavior validated at phone, tablet, laptop and desktop widths.
- Existing business logic and APIs unchanged by visual migration.
- Visual-regression and interaction tests run before merge.
