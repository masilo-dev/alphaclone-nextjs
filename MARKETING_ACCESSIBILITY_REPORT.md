# Marketing Accessibility Report

- The complete atmosphere is `aria-hidden` and has no focusable descendants.
- Every atmospheric layer uses `pointer-events: none`.
- Reduced motion stops continuous material deformation and pointer response.
- The central content safe zone is not occupied by opaque forms.
- Existing skip navigation, focus rings, semantic headings, route announcements, mobile dialog focus management, and keyboard escape behavior are preserved.
- Interaction feedback does not rely on motion alone.
